# F2BF Booklet Slideshow Plan

## Source Material

The slideshow adapts the **Free to be Faithful 8-page promotional booklet** — an initiative of the Institute for Christian Studies — into a 16:9 widescreen presentation. Content spans: mission, three pillars (Program / Resource / Community), a 2025-2026 timeline of courses and events, a speaker gallery of 12 voices, a call to action, and contact details.

---

## Design Principles (Best Practices Applied)

| Principle | How we apply it |
|---|---|
| **One idea per slide** | Each booklet section becomes 1-3 slides; no slide carries more than one message. |
| **6x6 rule** | Max 6 bullet points, max 6 words each. Body text stays under 30 words per slide. |
| **Visual hierarchy** | Large display type for headings (36-54 pt), concise body text (18-24 pt), red accent for emphasis. |
| **Font pairing** | Playfair Display (headings) + Source Sans 3 (body) — matching the booklet and website exactly. |
| **Color palette (3-5 colors)** | Teal Deep `#0F2631`, Teal `#1B3A4B`, Red `#C83C2C`, Cream `#F0EBE3`, White `#FFFFFF`. |
| **Contrast / accessibility** | Light text on dark backgrounds (cream on teal) passes WCAG AA. Red used only for accents, not body text. |
| **Full-bleed images** | Hero/divider slides use full-bleed photography with gradient overlays (matching booklet treatment). |
| **Consistent layout** | Repeatable slide masters: Title, Section Divider, Content, Speaker Card, Timeline, CTA. |
| **Narrative arc** | Context (why F2BF exists) -> Content (what it offers) -> Proof (timeline + voices) -> Closure (join the movement). |
| **Aspect ratio** | 16:9 widescreen — standard for screens, projectors, and video calls. |

```
  Grain overlay (SVG noise filter, mix-blend-mode: overlay)
  Gradient overlays on photography (teal gradients, 3-4 stops)
```

## Recommended Output Format

**PPTX (PowerPoint)** is the best format for this slideshow:

- **Editable**: Staff can update text, swap images, and adjust layouts without developer help.
- **Portable**: Works in PowerPoint, Google Slides, Keynote, and LibreOffice Impress.
- **Presenter-ready**: Supports speaker notes, animations, and presenter view.
- **Print-friendly**: Can export individual slides as high-res images or PDFs for handouts.
- **Brand-consistent**: Slide masters lock in fonts, colors, and layouts.
